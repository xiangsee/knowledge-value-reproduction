# 研究修订0.5.1：边界与再生产压力测试

日期：2026-09-28。基于v0.5.0的补丁修订，不覆盖0.5历史记录。

状态：将后续组织层压力测试暴露出的边界问题回接统一框架；不是新增企业事实审计、因果验证或通用量表。

## 1. 为什么是0.5.1而不是新框架

v0.5.0已经把Visibility—Accessibility—Reproduction纳入统一框架。后续研究没有推翻三维，而是暴露四个需要收紧的地方：

1. V不仅要看见知识和价值，也要看见能力依赖；
2. A不仅是检索和使用，还要问真实知识能否进入承担责任的决策；
3. R必须区分保存、恢复、迁移、扩展和更新，并允许主动淘汰失效知识；
4. R不是企业成功、收益或价值捕获的充分条件。

因此本版是边界和操作化补丁，不新增第三条主线、第二套企业模型或总分。

## 2. 纳入核心的最小变化

| 项 | 0.5.1处理 |
|---|---|
| Dependency Visibility | 并入V；记录能力依赖的人、数据、代码、工具、关系、权限、外部基础设施和制度条件 |
| Decision Accessibility | 并入A；与Retrieval、Interpretation一起按任务观察 |
| R五过程 | Preserve、Recover、Transfer、Extend、Renew；Renew包含纠错、淘汰失效知识和探索 |
| Reproductive Gain | 作为R的结果描述：相对适当反事实，下一期可靠行动边界扩大 |
| R≠Value | 作为硬边界；知识—能力接续与价值—配置反馈分别记录 |
| H07 | 新增“复用—退役张力”，允许高复用同时制造路径依赖和重构成本 |

## 3. 没有升格的专题概念

Generate/Absorb/Combine/Embed/Replicate/Reconfigure六机制、Knowledge Half-life、Replication Cost、Flow Friction、Reconfiguration Cost、Retirement Lag、Knowledge Stack、Knowledge Architecture等继续作为组织层分析或测量候选，不进入跨个人—组织—国家的总框架主结构。

Knowledge Carrier也不冻结为封闭七分类。继续按具体任务记录人、身体实践、文件/数据/程序、工具设备、协作关系、组织惯例及必要制度/物质条件；新的模型、平台、架构型载体按功能加入。

## 4. 反证边界

框架必须允许至少四种不利结果：

- V提高而A无改善；
- A提高而R无改善或下降；
- R较强但价值实现/捕获不足；
- 复用效率提高却延长失效知识退役、增加重构难度。

这些不是“例外需要解释掉”，而是能够改变命题边界的研究结果。

## 5. 下一步

停止继续扩概念。组织层优先完成两类材料：一是1998—2025民营500强知识可见度时间轴的原始来源核验；二是按换人、换技术、换组织、换环境记录真实能力再生产压力事件。个人层继续AI-KCF窄场景先导；国家层只保留必要接口。

本补丁不把研究对话中的具体企业案例直接写成已经核验的公开证据。
