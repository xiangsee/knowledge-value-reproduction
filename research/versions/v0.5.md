# 研究修订0.5：可见、可调用、可再生产

日期：2026-09-27。对应公开版本：v0.5.0。

状态：按用户本轮要求完成概念整合和组织层研究入口设置；不是新增实证证明。前序公开基线为v0.4.0（提交275cd7eebd3f66396ac0f395ad0fd46ef510a714），历史版本和实验材料保持不变。

## 1. 纳入的研究输入

用户要求将民营500强研究中再次出现的“可见性×可调用性”，接回既有“知识、能力与无形价值的显现和再生产”，而不另起新模型。

采用的核心表达（用户输入摘录）：

> 可见不等于可调用，可调用也不等于可增长。
>
> 看得见、调得动、长得出。

本版规范化为：**可见性、可调用性、可再生产性**，英文短名为**Visibility—Accessibility—Reproduction**。“增长”在解释中保留，但以保存、恢复、传递、扩展、更新及其持续条件界定R，避免数量增长替代能力形成。

本页是公开研究整合记录，不是私人对话全文或已确认企业研究结果的转录。

## 2. 采用与修订

| 输入表达 | 本版处理 | 理由 |
|---|---|---|
| 可见—可调用—可再生产 | 纳入主框架、首页、概念及既有命题映射 | 将原有调用/可执行化机制明确为独立诊断维度，不重复立项 |
| Visible → Accessible → Reproductive | 正式短名使用名词式；默认并列V、A、R | 不把传播箭头变成所有场景的必然先后关系 |
| 看得见、调得动、长得出 | 保留 | 简明表达三个不同问题；R不要求每次调用都增长 |
| 知识成为长期资本要依次通过三个门槛 | 不采纳为强定义 | 可持续使用的既有经济资源与持续创造新能力的机制不同；非竞争性复制、默会使用等也不应被排除 |
| 500强28年提供组织层实证场 | 纳入组织层研究入口，具体窗口和证据待核验 | 不能把研究意图、轮换榜单或对话中的结论视为完整固定面板 |
| 华为、美的、吉利、腾讯固定面板 | 保留为候选企业追踪名单 | 主体、年份和字段可比性未在本轮审计，不宣称已完成面板 |

## 3. 不是新理论，原结构保留

两条主线仍是价值显现与能力再生产；三维用于观察知识承载系统；两个循环仍研究实践、调用、评价、配置和更新。资源保存、当前表现、人的能力、系统接续与价值分配五类结果继续分别记录。

六项命题H01—H06编号不变，只增加V/A/R对应。理论地图沿用既有来源；没有新增未经复核的论文、企业事实或证据等级。首个专业证据判断样本维持原有先导状态和公开曝光边界。
