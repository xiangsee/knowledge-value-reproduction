# 待检验命题

编号是稳定引用标识，不是已验证结论。全部状态为 `proposed`；文献提供局部线索，不证明整个跨层级命题。0.5.1新增H07，并把既有命题按V—A—R与价值反馈重新收紧；这不是把三维变成因果定律。

| ID | 候选命题 | 初始检验 | 能改变判断的结果 |
|---|---|---|---|
| H01 | 可调用知识与反馈安排可能改善接收者保持、迁移和纠错，但A提高本身不保证R提高 | 同模型、同总时间的K×F比较；固定质量门槛；基线、未曝光延迟任务与迁移任务 | 检索/调用改善只提高当期措辞或速度；直接协作已足够；延迟保持与迁移无增量或更差 |
| H02 | 资源保存、可调用性与能力恢复/迁移成本可能背离，尤其在关键载体或依赖变化时 | 换人、换题、换工具、换依赖；记录Carrier、Dependency、质量门槛、恢复时间和全成本 | 保存完整稳定预测低成本恢复；差异主要来自任务/标准改变而非接续机制 |
| H03 | 能力可获得性、可再生产性与原持有者收益现值可能不同步 | 可靠性、接入范围、价格、归属、价值捕获和全成本分开跟踪 | 价格/收益变化完全由质量变化解释；能力并未扩散或R并未变化 |
| H04 | 显现可能通过决策可调用性和资源配置反馈影响形成与维护条件 | 对同样真实信息采用不同证据表达/决策通道；跟踪是否改变使用机会、维护、培养、责任和后续接续 | 只有展示数字改变，没有决策/配置变化；配置变化与后续接续无关 |
| H05 | 不同主体和层级的V、A、R与收益可能不同步 | 分开观察个人、团队、组织、职业网络和公共系统的变化与流动 | 所谓损失只是主体间转移，或各层级在关键结果上稳定同步 |
| H06 | AI可能显著降低V→A的部分成本并扩大探索机会，但A→R的影响取决于验证、反馈、实践、更新与退役机制 | 记录检索/调用成本、现实核验、未曝光迁移、错误纠正、探索停止决策和全成本 | A改善稳定伴随R改善且不依赖这些条件；或AI只启动更多项目，没有形成可靠新能力 |
| H07 | 对既有知识的高复用可能同时降低重复学习成本并提高退役、替换或重构旧知识的难度；长期R取决于能否识别并淘汰失效知识 | 选择平台/routine/技术换代事件，记录复用深度、失效信号、退役滞后、替换成本与新任务表现 | 高复用并未增加任何锁定或退役成本；观察到的滞后主要由监管、实物资产或外部约束解释 |

专业证据判断样本主要服务H01，并为H02准备规范；H03—H07不由这个样本完成验证。接口与证据见 [理论地图](../theory/README.md) 和 [台账](../evidence/README.md)。

每次更新记录：原命题、来源/观察、支持/修正/反证/扩展/指标、适用范围与剩余缺口。负结果、停止方向也是研究结果，不以文件数或引用数评价进展。

## 0.5.1三维结构与命题位置

| 命题 | 主要位置 | 必须保留的边界 |
|---|---|---|
| H01 | A→R | 当前调用成功不能替代延迟保持、迁移或纠错证据。 |
| H02 | Carrier/Dependency变化下的V/A/R | 文件、目录或IP资源保存不能替代任务恢复和迁移。 |
| H03 | A/R与Value | 能力形成、价值实现和价值捕获分别记录。 |
| H04 | V→Decision A→Allocation→R | 看见价值不等于配置改变；配置改变不等于接续成功。 |
| H05 | 跨层级V/A/R | 同一工具对个人、组织和社会网络可能产生不同方向结果。 |
| H06 | AI条件效应 | 重点检验A变容易以后，R是增强、无变化还是被侵蚀。 |
| H07 | R中的复用—退役张力 | Renew同时包括学习新知识和停止复制失效知识。 |

[民营500强研究接口](organization/private-enterprise-500.md)主要为组织层V历史、A载体变化和R压力测试提供候选材料。它不是对任何命题的验证，也不计算V×A×R总分。
