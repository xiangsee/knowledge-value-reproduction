# 概念与测量边界

以下是本项目工作定义，不声称各学科已共享同一定义。出处入口见 [理论地图](../theory/README.md)。

| 概念 | 本库用法 | 必须区分 |
|---|---|---|
| 不可见 | 对特定主体和决策未被理解、记录或承认 | 不存在、无价值、可交易资产 |
| 可见性 V | 对某一观察者和决策能够被识别、理解并以适当证据表达 | 可见不等于公开全部信息、货币化或完整编码 |
| 依赖可见性 | 一项能力所依赖的人、知识、数据、代码、工具、设备、关系、权限、外部基础设施和制度条件能够被识别和追溯 | 依赖可见不等于本主体拥有、控制或能够替代该依赖 |
| 可调用性 A | 特定使用者能够找到、在适当权限下获取、理解、组合和可靠使用，并在需要时进入任务和决策 | Accessibility在本库包含usability；有检索/API不等于有效调用；有人知道不等于组织据此决策 |
| 决策可调用性 | 与任务真实相关的知识能够穿过必要的组织、权力和信息边界，进入承担责任的判断与资源配置 | 某个人或部门知道，不等于决策者获得了真实、完整且可用的信息 |
| 可再生产性 R | 在一定时间尺度内支持知识与能力的保存、恢复、传递/迁移、扩展和更新 | 不是数量自动增加、每次调用都学习或单纯结果复现；恢复旧表现不等于完整再生产 |
| 再生产增益 | 相对适当反事实，使用和反馈后下一期可靠行动边界扩大 | 文件、专利、调用、产出、收入或估值增加不能直接替代 |
| 知识退役滞后 | 某项知识、规则或载体已不再适用，到组织停止围绕其配置资源之间的时间差；主要作为组织层测量元数据 | 不作为统一框架的新维度，也不等同于客观技术半衰期 |
| 知识承载系统 | 内容、载体、合作与实践条件支持行动 | 载体、产权和会计边界 |
| 编码 | 表达为文字、数据、规则、案例或程序 | 表达完整性和实际可用性 |
| 可执行化 | 指定条件下能够完成任务 | 模仿表现、理解、接收者学习 |
| 证据化 | 能力及效果形成可追溯可检验记录 | 记录存在与充分支持命题 |
| 价值显现 | 价值进入认识、比较和决策 | 货币化、入表、交易、公共决策 |
| 资本形成 | 面向跨期效果形成经济资源的过程 | 既成收益、权利和会计确认 |
| 能力 | 明确条件下可靠行动、判断和更新的本领 | 内部能力与系统联合能力 |
| 再生产 | 保存、恢复、传递、扩展、更新及其条件 | 机械复制、社会位置延续、知识创新 |
| 恢复成本 | 条件变化后恢复质量门槛的投入 | 资料完整率和完全自给自足 |
| 学习不足 | 相对适当反事实形成的新能力较少 | 既有能力衰退 |
| 人类发展能力 | 实际可选择的行动与生活机会 | 狭义任务绩效和劳动收入现值 |
| 经济估值 | 给定方法、主体、范围和假设的估计 | 全部知识和公共价值的直接测量 |

## 三维结构的使用边界

正式短名采用Visibility—Accessibility—Reproduction；中文传播表达为“看得见、调得动、长得出”。这是本项目工作表达，不冒充既有文献统一术语。“可增长性”可作解释性用语，但不替代可再生产性。

V、A、R是可分别观察但可能相互影响的维度，不是强制阶段、统计独立假定或三个相乘的分数。需要标明观察者/使用者、任务、时间、载体、依赖、权限、质量和全成本；未知不等于零。**V不自动推出A，A不自动推出R，R也不自动推出经济或公共价值结果。**

“调用”包括由人、团队、流程、技术架构或机器实现的使用，不限于软件API。组织层可进一步区分Retrieval（找得到）、Interpretation（理解适用条件和边界）与Decision（进入实际判断和资源配置）。对外部观察者不可见，不表示内部不能调用；在保密和合法权限下使用，不以完全公开为前提。

“长得出”以合适的时间跨度和系统边界理解。R按Preserve、Recover、Transfer、Extend、Renew分别记录；Renew至少允许观察纠错、淘汰失效知识和探索。保持可靠能力、培养接续者、恢复功能和形成新能力分别记录；不要求所有旧技能永久保留。人的、组织的及社会网络的变化不可互相替代。

不把三维结构写成“资本成立的三个必经门槛”。可持续使用的经济资源与可持续产生新能力的机制有关，但不是同一个定义。价值结果仍需独立检验，不能由三维状态自动推出。

## 不可混用的四组变化

能力形成／价值识别／重估／重分类，不能用同一个“增长”概括。

投资流量／资本存量／服务流量，不能因货币单位相同直接相加。

成果创建／产权或控制／收益获得，不预设主体相同。

个人学习／组织接续／职业代际培养／国家能力扩散，不由同一测验替代。
