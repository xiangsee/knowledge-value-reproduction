# 理论地图：接口，而不是作者堆叠

书目见 [sources.json](../evidence/sources.json)。`inherited_record`沿用底稿来源记录，不是本次重新核验；`dialogue_lead`是初始对话线索，未在本次迁移中完成独立原文审计。

| 理论线 | 入口 | 解释什么 | 不能替代什么 |
|---|---|---|---|
| 财富与形成能力 | List、Romer、国家创新系统L01—L03 | 成果与持续形成成果的条件 | 产值不等于形成能力 |
| 默会及分布式认知 | Polanyi/Collins线索L04；Hutchins R06；Clark/Chalmers R14 | 载体、身体/社会条件、人机系统 | 工具表现不等于个人内化；国家不等于单一心智 |
| 资本形式与再生产 | Bourdieu R03；Marx R02 | 载体转换、内化成本、机会和生产条件 | 文化资本不是可直接入账金额 |
| 组织知识与转移 | Kogut/Zander R04；Nonaka、Cohen/Levinthal、Argote L05—L07 | 合作、吸收和接收机制 | 文件交付不等于接续能力 |
| 学习、探索与更新 | Zollo/Winter R05；Arrow、March、Mesoudi/Thornton L08—L10 | 实践如何更新能力 | 重复、维护和探索投入不保证有效 |
| 无形资本与确认 | CHS R08；IAS 38 R09；ONS R18—R19 | 经济投资、核算与会计边界 | 投入、识别和能力增长不能混算 |
| 跨层级制度语言 | Ostrom R01；经济复杂性R13 | 框架/理论/模型与网络中间层 | 不预设同一种模型解释所有主体 |
| 价值显现与分配 | Espeland/Stevens R07；Teece L11 | 共同尺度、控制、收益和互补资产 | 创造价值不等于创造者获益 |
| 人类发展与公地 | UNDP L12；Hess/Ostrom L13 | 非货币价值、行动机会、共享治理 | 人的意义不等于竞争优势 |
| AI与能力证据 | R10—R12、R15 | 表现、保持和设计差异 | 异质研究不能相加成一般AI效应 |
| 测量效度 | AERA/APA/NCME R20 | 分数解释、等值、无关差异与试用 | 自编量表和结构检查不是有效性证明 |

L系列只是必要出处或回查线索，部分理论全文仍需深入阅读。目录覆盖不等于理论工作完成。

优先比较解释同一观察的竞争机制：吸收、反馈学习、任务选择、人员/协作变化及价格/分配变化。现有理论无法区分关键机制时才扩大范围。

文献事实、作者理论、项目迁移解释和待检验命题分开记录。每条理论需要说明解释哪一步、缺哪项证据，而不是只增加名字。
