# 知识、能力与无形价值的显现和再生产

**Knowledge, Capability & Value: Visibility and Reproduction**  
《详见》XIANGSEE · 个人—组织—国家的统一研究框架

> 价值显现告诉我们有什么值得利用；能力再生产追问，利用之后是否还能继续创造。

本仓库是该统一框架的公开主库，保存概念、理论来源、待检验命题、证据边界、版本演进与研究材料。它不是单独的AI学习试题库，也不是给个人、企业或国家打总分的估值产品。

**当前基线：v0.5.1｜2026-09-28｜补充依赖可见性、决策可调用性、再生产增益与价值边界；未完成统一模型的实证验证。**

## 核心表达：看得见、调得动、长得出

**可见性 · 可调用性 · 可再生产性**  
**Visibility · Accessibility · Reproduction**

可见性：对谁、在哪种决策中，知识与价值能够被识别和表达？可调用性：特定使用者能否在适当权限和条件下找到、理解、组合并可靠使用？可再生产性：系统能否保存、恢复、传递、扩展与更新知识和能力？

**可见不等于可调用，可调用不等于可再生产，可再生产也不自动等于价值实现或价值捕获。** 三者是联合诊断维度，不是必然依次发生的阶段，不是乘积公式，也不是企业成功或资产估值公式。“长得出”包含保持、纠错、接续、扩展和更新，不要求每次调用都产生新知识。

v0.5.1进一步要求：V不仅记录知识与价值是否可见，也记录关键能力依赖是否可见；A区分检索、解释与决策可调用性；R以保存、恢复、传递/迁移、扩展和更新为过程，并用“再生产增益”描述下一期可靠行动边界是否扩大。

两条主线保留；三维结构明确原有“可执行化与利用”的位置；两个循环继续研究调用、实践、配置和更新之间的机制。详见[统一框架](docs/FRAMEWORK.md)。

## 研究什么

**价值显现：**已有知识、能力与无形价值，怎样通过表达、证据、测量和制度承认进入认识与决策？对谁不可见，在哪种决策中不可见？

**能力再生产：**知识及其承载条件怎样被保存、恢复、传递、扩展和更新？当前的使用方式怎样影响下一轮知识、能力和价值的形成？

基本分析单位是**知识承载系统**：人、身体技能、数据和文件、工具、协作关系、惯例与必要的制度/物质条件。承载、控制、组织和核算边界分别记录。

个人、组织和国家共用问题结构，不预设共用一个生产函数、产权主体或价值总额。团队、职业共同体、产业网络和公共机构是必要的中间层。

## 与已有研究的关系

**AI-KCF**研究知识如何形成可跨期调用的经济资源与组织能力；经济资本形成不等于法律权利或会计确认。**知识承载系统**研究知识在哪里，怎样保存、迁移、恢复和更新。**全球价值可见化**研究哪些价值未进入认识、核算与决策，以及显现怎样改变配置。

本库整合上位问题和公共研究接口，不自动迁移其他专题的非公开资料，不改变其他仓库的可见性。自然、文化、福祉等价值不能全部归入知识资本。

## 当前已做与未做

已整理0.2—0.4公开底稿、0.5三维整合记录、0.5.1边界修订及理论/命题索引；首个样本包括六条判断规则、四组真实文献练习、三套共十二道虚构候选题、评分锚点和空白记录模板。

民营500强研究接为组织层观察入口，不另立模型；候选企业为华为、美的、吉利、腾讯，完整面板和具体结论仍待原始材料核验。本轮未导入企业数据，未重新审计全部外部来源。

**尚无参与者数据，尚未完成独立专家审查、题目等值、评分效度或能力再生产效果检验。**结构校验只检查文件，不证明研究结论。公开题目和答案不能作为保密留出材料。
