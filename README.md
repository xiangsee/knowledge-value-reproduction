> 价值显现告诉我们有什么值得利用；能力再生产追问，利用之后是否还能继续创造。

## 研究什么

**价值显现：**已有知识、能力与无形价值，怎样通过表达、证据、测量和制度承认进入认识与决策？对谁不可见，在哪种决策中不可见？

**能力再生产：**知识及其承载条件怎样被保存、恢复、传递、扩展和更新？当前的使用方式怎样影响下一轮知识、能力和价值的形成？

基本分析单位是**知识承载系统**：人、身体技能、数据和文件、工具、协作关系、惯例与必要的制度/物质条件。承载、控制、组织和核算边界分别记录。

个人、组织和国家共用问题结构，不预设共用一个生产函数、产权主体或价值总额。团队、职业共同体、产业网络和公共机构是必要的中间层。

## 与已有研究的关系

**AI-KCF**研究知识如何形成可跨期调用的经济资源与组织能力；经济资本形成不等于法律权利或会计确认。**知识承载系统**研究知识在哪里，怎样保存、迁移、恢复和更新。**全球价值可见化**研究哪些价值未进入认识、核算与决策，以及显现怎样改变配置。

本库整合上位问题和公共研究接口，不自动迁移其他专题的非公开资料，不改变其他仓库的可见性。自然、文化、福祉等价值不能全部归入知识资本。

## 当前已做与未做

已整理0.2—0.4公开底稿及理论/命题索引；首个样本包括六条判断规则、四组真实文献练习、三套共十二道虚构候选题、评分锚点和空白记录模板。

**尚无参与者数据，尚未完成独立专家审查、题目等值、评分效度或能力再生产效果检验。**结构校验只检查文件，不证明研究结论。公开题目和答案不能作为保密留出材料。
