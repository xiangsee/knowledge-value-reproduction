# 《详见》｜知识、能力与无形价值的显现和再生产
## 研究样本 0.4：专业证据判断的知识包与试用题

日期：2026-09-27。前序：本对话研究底稿0.1—0.3。

**状态：公开演示/先导材料。来源核验沿用历史记录，本次发布未重查全部外部来源。未开展人员实验，未校准题目难度，未验证评分信效度。**

这是一项窄任务的研究样本，不是人的整体能力测验，更不是组织或国家知识资本估值模型。它研究：已有的证据判断经验被整理为可调用材料后，是否帮助接收者作出更可靠、可保持、可迁移的判断。

### 三个概念结果

1. 本任务的“专家知识”不只是一批结论，还包括何时接受、何时缩小结论、何种新证据会改变判断。
2. 会识别过度推论与会保留已经得到支持的有限结论，同样重要；不能把一律否定训练成“严谨”。
3. 知识包的交付、即时任务效果、接收者保持/迁移、组织换人后的恢复、经济与公共效果分别验证。不因为完成了前一步，就自动确认后一步。

以上是本轮设计判断，不是本轮已经证明的普遍因果规律。

### 使用顺序

先由一位未参与出题的领域读者审查练习和评分边界，再做少量认知访谈与计时试用。题目、读题成本和评分歧义被修正后，才讨论正式随机试验。A/B/C现在仅为同一蓝图下的候选卷，并未达到心理测量意义上的平行形式标准。[S5]

所有已在本对话或附件中曝光的题目都只能用于演示、先导或训练。对看过材料的人开展正式效果检验时，必须另制未曝光题，不得靠换名字、换数字冒充未见题。
